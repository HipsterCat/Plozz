# ProviderKinoPubDemo

Плозз на реальных данных кино.паба — без сервера, без аккаунта, без сети (кроме
картинок). Нужен, чтобы судить внешний вид на русских названиях и настоящих
постерах, а не на латинских заглушках.

## Запуск

```bash
SIMCTL_CHILD_PLOZZ_KINOPUB_DEMO=1 xcrun simctl launch booted com.thatcube.Plozz
```

В Xcode: в схеме `Plozz` добавить переменную окружения `PLOZZ_KINOPUB_DEMO=1`.

Флаг действует только в Debug. Без него сборка Плозза не отличается от обычной
ни одним байтом поведения.

## Что подменяется

Ровно два объекта — хранилище аккаунтов и реестр провайдеров:

| | Обычная сборка | Демо |
|---|---|---|
| Аккаунты | Keychain | `KinoPubDemoAccountStore` в памяти |
| Провайдер | Jellyfin / Plex / шара | `KinoPubDemoProvider` из JSON |

Всё остальное — настоящее: тот же Home, тот же герой, те же полки, те же
настройки. В этом и смысл: на экране Плозз, а не макет Плозза.

Демо ничего не пишет на диск. Аккаунт живёт только в процессе, Keychain не
трогается, выход из демо оставляет устройство ровно таким, каким оно было.

## Каталог

`Resources/KinoPubDemoCatalog.json` — 140 позиций, отобранных по наличию
описания, широкого фона и лого (без них герой выглядит пустой плитой) и по
рейтингу Кинопоиска ≥ 6.5 при ≥ 5000 голосов.

Постеры — `m.staticpop.net` (2:3 и wide), фон и лого — Кинопоиск, ужатые до
1920×1080 и 320×320: `orig` отдаёт 3 МБ на кадр, чего телевизору не нужно.

Пересобрать каталог:

```bash
python3 tools/kinopub-demo/build_catalog.py \
  --record ../kinopub-apple-client/tools/metadata-ingest/data/record.db \
  --out Sources/ProviderKinoPubDemo/Resources/KinoPubDemoCatalog.json
```

## Чего в демо нет

- **Плеера.** `playbackInfo` бросает ошибку. Демо про внешний вид; фальшивый
  поток дал бы только странно падающий плеер.
- **Настоящих серий.** У сериалов синтезируются сезоны — иначе страница
  сериала упирается в пустоту. Эпизодов нет.
- **Записи прогресса.** `reportPlayback` — пустышка.
